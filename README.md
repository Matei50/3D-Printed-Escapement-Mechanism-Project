\## Overview



This repository contains my 3D modeling project created in Fusion 360, based on the Clock One mechanical clock concept.



Clock One is a mechanical clock made from 3D printed parts. It uses a weight-driven mechanism, a pendulum, gears, and a Graham / deadbeat escapement to control the movement of the clock.



The purpose of this project was to understand how a mechanical clock mechanism works and to recreate/adapt its main components in Fusion 360.



\## Project Description



The model represents a 3D printed mechanical clock mechanism. The clock includes hours, minutes and seconds, and it is powered by weights.



The mechanism uses a Graham, also known as deadbeat escapement, which controls the release of energy from the gear train. The pendulum regulates the movement and can be adjusted using a nut in order to fine-tune the speed of the clock.



The clock also includes ratchets on the pulley system, making it easier to rewind the mechanism.

\## How the Mechanism Works



The clock is powered by a falling weight. As the weight moves downward, it transfers energy to the gear train.



The escapement releases the energy step by step, preventing the gears from spinning freely. The pendulum controls the rhythm of the escapement, allowing the clock to measure time.



The adjustment nut on the pendulum can be moved to make the clock run slightly faster or slower.
